## Download the deployment files

Create an empty directory, retrieve the Compose manifest and its example configuration, then create your `.env` file.

```bash [Terminal]
mkdir alexandrie && cd alexandrie
curl -O https://raw.githubusercontent.com/Smaug6739/Alexandrie/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/Smaug6739/Alexandrie/main/.env.example
```

For a local trial, the provided values work as-is. Start the stack:

```bash [Terminal]
docker compose up -d
docker compose ps
```

Then open <http://localhost:8200>. No account is created automatically: sign up from the welcome screen to create the first account.

## Check services

The `mysql`, `rustfs`, `backend`, and `frontend` containers should be running. If something fails, inspect their logs:

```bash [Terminal]
docker compose logs -f backend frontend
```

By default, the frontend listens on port `8200`, the API on `8201`, MySQL on `3307`, and RustFS on `9005` when the `.env.example` values are used.

Before exposing the service publicly, change every secret and configure production URLs in [configuration](/deploy/configuration).
