For a first installation, use a Linux or macOS machine with Docker Engine and the Docker Compose plugin. Windows also works through Docker Desktop.

## Recommended resources

For a small group, plan for at least 2 vCPU, 4 GB of memory, and persistent disk space sized for your media and backups. Actual needs depend mostly on file volume, concurrent users, and database size.

For production, also prepare:

- a domain name for the interface, for example `wiki.example.com`;
- ideally a subdomain or public path for file storage;
- a reverse proxy that terminates TLS;
- random secrets for MySQL, RustFS, and JWT tokens.

::warning
---
title: Do not expose internal services
---
MySQL and the S3 API should normally not be reachable from the Internet. Only the frontend, and optionally the public file endpoint, should be exposed through your reverse proxy.
::

Read the [production guide](/deployer/production) before making an instance public.
