Copy `.env.example` to `.env`, then change the necessary values. Never commit the final `.env` file.

## Public URLs

| Variable | Purpose |
| --- | --- |
| `FRONTEND_URL` | Public URL of the interface. |
| `API_URL` | Public API URL used by the browser. |
| `CDN_URL` | Public origin serving S3 objects. |
| `CDN_ENDPOINT` | Object path prefix, `/alexandrie/` by default. |

File links are composed as `<CDN_URL><CDN_ENDPOINT><object-path>`.

## Security and behaviour

| Variable | Purpose |
| --- | --- |
| `COOKIE_DOMAIN` | Common frontend/API domain, without a protocol. |
| `ALLOW_UNSECURE` | `true` for local HTTP; `false` for production HTTPS. |
| `JWT_SECRET` | Token signing secret; changing it signs every user out. |
| `ADMIN_ACCOUNTS` | Optional comma-separated list of administrator user IDs. |
| `CONFIG_DISABLE_LANDING` | Disables the public landing page. |
| `CONFIG_DISABLE_SIGNUP` | Prevents new registrations. |
| `CONFIG_DISABLE_NATIVE_LOGIN` | Disables username/password login. |
| `CONFIG_HIDE_NATIVE_LOGIN` | Hides the native form. |
| `CONFIG_OIDC_PROVIDER_AUTO_REDIRECT` | Provider name to redirect to automatically. |

::warning
---
title: Cookies and subdomains
---
For `wiki.example.com` and `api.example.com`, use `COOKIE_DOMAIN=example.com`. Do not include `https://` or a path. An incorrect value commonly creates a login loop.
::

## Data services

| Variable | Purpose |
| --- | --- |
| `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_ROOT_PASSWORD` | MySQL database and credentials. |
| `MINIO_BUCKET` | Main S3 bucket, `alexandrie` by default. |
| `RUSTFS_ACCESS_KEY`, `RUSTFS_SECRET_KEY` | Credentials for the included RustFS service. |
| `MINIO_SECURE` | Enables TLS from backend to S3 endpoint. |
| `MINIO_CA_PATH` | Private CA certificate path mounted in the backend. |
| `MINIO_INSECURE_TLS` | Disables TLS verification; temporary troubleshooting only. |
| `SMTP_HOST`, `SMTP_MAIL`, `SMTP_MAIL_FROM`, `SMTP_PASSWORD` | Password-reset email delivery. |

For backend settings not exposed by environment variables, mount a `backend/config.toml` compatible file and set `CONFIG_PATH`.
