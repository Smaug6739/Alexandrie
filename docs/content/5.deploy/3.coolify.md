[Coolify](https://coolify.io/) is an alternative way to deploy Alexandrie on your own server.

Alexandrie is available directly in Coolify's list of services. This means that you can create an Alexandrie deployment from Coolify without manually copying or modifying the `docker-compose.yml`.

The deployment still uses the same Alexandrie configuration and environment variables as a regular Docker deployment.

## Create the service

1. Open your Coolify instance.
2. Select the project and environment where you want to deploy Alexandrie.
3. Create a new resource.
4. Select **Alexandrie** from the available services.
5. Select the server where Alexandrie should run.
6. Configure the required domains and environment variables.
7. Deploy the service.

You do not need to manually edit the Alexandrie Docker Compose file.
