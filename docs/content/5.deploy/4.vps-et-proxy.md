On a VPS, install Docker and Docker Compose, place the files in an Alexandrie-specific directory, then choose a reverse proxy. The examples use three subdomains: `wiki.example.com`, `api.example.com`, and `files.example.com`.

Set these URLs, `COOKIE_DOMAIN=example.com`, and `ALLOW_UNSECURE=false` in `.env`. Point their DNS records at the VPS before requesting TLS certificates.

## Nginx

Create one virtual host per origin. Nginx must pass the `Host` and proxy headers; enable TLS with Certbot or your usual method.

```nginx [nginx]
server {
  listen 443 ssl http2;
  server_name wiki.example.com;
  # ssl_certificate … ; ssl_certificate_key … ;
  location / {
    proxy_pass http://127.0.0.1:8200;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  }
}

server {
  listen 443 ssl http2;
  server_name api.example.com;
  # same TLS directives
  location / {
    proxy_pass http://127.0.0.1:8201;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  }
}
```

Add a third virtual host with `server_name files.example.com` and `proxy_pass http://127.0.0.1:9005`. Adjust the port if you do not use the example environment values.

## Caddy

Caddy obtains and renews certificates automatically once DNS is ready.

```caddy [Caddyfile]
wiki.example.com {
  reverse_proxy 127.0.0.1:8200
}

api.example.com {
  reverse_proxy 127.0.0.1:8201
}

files.example.com {
  reverse_proxy 127.0.0.1:9005
}
```

## Traefik

Connect Traefik and Alexandrie to a shared Docker network, then add labels to each routed service. This is the frontend example; duplicate it for the API and RustFS, changing hostname and internal port.

```yaml [docker-compose.override.yml]
services:
  frontend:
    networks: [alexandrie-network, proxy]
    labels:
      - traefik.enable=true
      - traefik.http.routers.alexandrie.rule=Host(`wiki.example.com`)
      - traefik.http.routers.alexandrie.entrypoints=websecure
      - traefik.http.routers.alexandrie.tls.certresolver=letsencrypt
      - traefik.http.services.alexandrie.loadbalancer.server.port=8200

networks:
  proxy:
    external: true
```

::warning
---
title: Do not copy ports blindly
---
With Traefik, target the container's **internal** port (`8200`, `8201`, `9000`), not necessarily the host-published port. With Nginx/Caddy, use the published port or an address reachable by the proxy.
::
