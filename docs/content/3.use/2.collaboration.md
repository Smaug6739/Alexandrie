Permissions can be applied to spaces and their content. Alexandrie distinguishes five levels:

| Level | Allows |
| --- | --- |
| None | No access to the content. |
| Read | View permitted content. |
| Write | Create and edit permitted content. |
| Admin | Manage the relevant structure and settings. |
| Owner | Retain full control over the scope. |

## Public sharing

A public link is useful when you need to share one document with someone without an account. Review what it includes first: treat a public link as content available to everyone who has it.

## Good practices

- Grant the lowest level required.
- Use workspaces to isolate sensitive projects.
- Revoke invitations and links that are no longer needed.
- Do not store secrets in documents; use a dedicated vault instead.
