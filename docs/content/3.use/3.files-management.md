Uploaded files are stored in an S3-compatible service. Alexandrie creates and uses the bucket set by `MINIO_BUCKET`, plus a related backup bucket.

## Media and previews

Add images, PDFs, audio, and video to documents or through the file manager. Public file URLs are built from `CDN_URL`, `CDN_ENDPOINT`, and the object path: verify them as soon as you deploy to production.

## Import and export

ZIP import/export tools help move groups of documents and resources. Always test an export on a staging instance before using it as a migration or restore process.

## Backup strategy

A usable backup covers two separate data sets:

1. the MySQL database (users, documents, permissions, and metadata);
2. S3 object storage (media, archives, and related backups).

Back them up regularly to a location separate from your server, encrypt archives, and periodically test a restore.
