Uploaded files are stored in an S3-compatible service.
This service is optional and can be disabled on your instance. If you disable it, you will not be able to upload files or use the export features.
::

## Features

The file manager is accessible from the sidebar (dock) or from the top bar. It lets you:

- upload files;
- preview images, audio, and video;
- download files;
- manage files (edit metadata, delete, move);

![file manager](/assets/cdn.png)

Files can be used in any document using markdown syntax or the media picker (in the editor toolbar).

You can also attach files to a document, which will make them appear in the document's metadata panel. This is useful for keeping track of files related to a specific document. If you delete a document, the attached files will also be deleted.

To attach a file to a document, you can directly drag and drop it into the editor and sidebar, paste it in the editor or if the file is already uploaded, you can edit its metadata and select the document to attach it to (in "Parent" field).

![attached files](/assets/attached-files.png)

## Supported file types

Supported file types can be configured by the instance administrator. By default, the following file types are supported:

- Images: `.jpg`, `.jpeg`, `.png`, `.gif`, `.svg`, `.webp`, `.bmp`, `.tiff`, `.ico`
- Audio: `.mp3`, `.wav`, `.ogg`, `.flac`, `.aac`, `.m4a`
- Video: `.mp4`, `.webm`, `.ogg`, `.avi`, `.mov`
- Documents: `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.txt`, `.md`
- Archives: `.zip`, `.tar`, `.gz`, `.rar`, `.7z`
- Other: `.csv`, `.txt`
