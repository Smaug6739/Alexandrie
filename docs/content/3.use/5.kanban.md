## General overview

To use the Kanban board, you need to create a category and add at least one document to it. The Kanban board will then display the documents in that category as cards, which can be moved between columns.

To enable the Kanban board, you need to go to the category list and click on the "Kanban" button in the top right corner. This will open the Kanban board for that category.

::tip
You can create multiple categories and put documents in the lower level categories. So you can have a Kanban board for each category. This is useful for organizing documents by project, team, or topic.
::

## Assigning users and use filters

To assign a user to a card, you need to the "Manage Assignments" button in the bottom right corner of the card. This will open a modal where you can select users to assign to the card.

You can assign multiple users to a card. The assigned users will be displayed in the card header.

You can then use the filters buttons to filter the cards by assigned users or by status. The filters are available in the top right corner of the Kanban board.
