Alexandrie lets you style a knowledge base without changing the actual content. The same note can look very different depending on the theme, document preferences, and metadata assigned to it. This is useful for creating a clean public wiki, a dense technical knowledge base, or a more editorial, polished workspace.

## Document metadata and styling

Every document can be customized in several ways:

- icon or emoji;
- color accent;
- thumbnail image or inline SVG;
- display theme;
- text presentation settings such as font family, size, and line height.

These settings are available from the document metadata modal, which is the place to adjust the visual identity of a node without editing the text itself.

![metadata modal](/assets/metadata.png)

### Icons and thumbnails

You can assign an icon or emoji to a document to make it easier to recognize in the sidebar tree or in lists.
For icons, you can use any SVG file or emoji. SVG will be displayed in color of the document accent.

Thumbnails are larger images that can be used to give a document a more visual identity. They are displayed in the document header and they must be square. You can use any SVG file.

::note
You can enable the "Use parent thumbnail" option from settings to inherit the thumbnail from the parent document / categories. This is useful for categories or workspaces that have a shared visual identity.
::

To use SVG, paste the SVG code directly into the thumbnail field. The system will sanitize it to remove any potentially unsafe content.

::tip
You can find free svg icons and thumbnails on following websites (used in demos pictures):

- [https://www.svgrepo.com/](https://www.svgrepo.com/)
- [https://undraw.co/illustrations](https://undraw.co/illustrations)

::

## Theme system

Themes are a central Alexandrie feature. A theme changes how a document is rendered without requiring you to rewrite the content. It affects the reading experience, not the source text.

Available styles include:

- **Alexandrie :** Default, colored and complete with all features. This theme support customization of the reading experience with font family, size, line height, and more.
- **LaTeX :** A classic academic style with serif fonts and a clean layout. It is suitable for research notes, papers, and technical documentation.
- **LaTeX colored:** A variant of the LaTeX theme with colored blocks
- **Modern:** A contemporary style with sans-serif fonts, larger headings, and a more visual layout.
- **Academic:** A scholarly style with serif fonts, clear headings, and a focus on readability.
- **Material:** A theme inspired by Material Design, with a clean and modern look, suitable for technical documentation and wikis.
- **Minimal:** A simple and clean style with minimal distractions.

This creates a very powerful workflow: write in one consistent format, then choose a presentation style that fits the audience.

## Colors & accents

You can completly change the accent color of the application in the settings. This will change the color of the top bar, buttons, and other elements.

You can also select a theme variant for the app between light, dark, for color scheme and between Default and Glassmorphism for the style. This will change the overall look of the application.

You can assign a color accent to a document to make it easier to recognize in the sidebar tree or in lists. The color is also used for the icon if it's an SVG.

Tags are automatically assigned a color based on the tag name. You can choose to display tags as monochrome in the settings. In that case, the tags will be displayed in application accent color instead of their own color. This is useful for a more uniform look.

## Other customization options

You can explore settings to see all available customization options. You can change the font family, size, line height, and more to create a reading experience that suits your needs.

You can also directly inject custom CSS in the settings to change the look of the application and documents. This is for advanced users who want to create a unique style or adapt the interface to their needs.

::warning
The custom CSS is applied to the entire application, not just a single document. Be careful when using it, as it can affect the layout and functionality of the app.  
Also note that selectors may change between versions, so you may need to update your custom CSS when upgrading Alexandrie.
::
