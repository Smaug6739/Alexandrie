The user management page is where administrators handle account creation for the instance. It is the recommended place to onboard people without requiring them to create their own accounts manually.

## Accessing user management

From the admin dashboard, open the user management section. This view lets you:

- create individual accounts;
- import accounts from CSV;
- review the current user list;
- prepare onboarding flows for teams and workspaces.

## Creating users

To create a new user, click the "Create user" button. You will be prompted to enter:

- username (required to identify the user)
- email (required to allow user setting their password)
- first name (optional)
- last name (optional)
- whether two-factor authentication is required

You can also import users in bulk from a CSV file. The CSV should have the following columns: `username`, `email`, `first_name`, `last_name`, and `require_totp`. The first two columns are required, while the last three are optional. The `require_totp` column should contain a boolean value (`true` or `false`) indicating whether the user must set up two-factor authentication.

![user management modal](/assets/admin-users.png)

### TOTP requirement

You can force a user to set up two-factor authentication during onboarding. This makes account security stronger for sensitive or shared deployments.

You can change this setting at any time after the account is created but the user will be prompted to set up TOTP the next time they log in if it is required.
If you want to force TOTP immediately, you can also revoke the user's session from the admin panel. This will force them to log in again and set up TOTP if it is required.

## Managing existing users

You can review the list of existing users in the user management section. For each user, you can:

- view their details (username, email, name, TOTP requirement);
- edit their details
- view their activity
- view their nodes
