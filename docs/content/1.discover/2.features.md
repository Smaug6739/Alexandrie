## Write without breaking your flow

Alexandrie's CodeMirror 6 editor combines Markdown authoring and rich preview. It includes syntax highlighting, synchronised scrolling, speech-to-text, keyboard shortcuts, and reusable snippets. Documents support tables, task lists, media, equations, and diagrams.

## Organise knowledge

Content lives in a hierarchy: **team → workspace → category → document**. Documents can be nested to naturally represent a guide, project, or business knowledge base. Full-text search and the command centre (`Ctrl` + `K`) make pages and actions easy to find.

## Collaborate and share

Workspaces can have multiple members. Alexandrie provides five access levels: none, read, write, admin, and owner. Invitations and public sharing links let you open a specific resource without exposing the rest of the instance.

## Manage files and media

Files are kept in S3-compatible storage: RustFS, MinIO, Garage, AWS S3, or another compatible provider. The app previews images, PDFs, audio, and video. A central file manager and diagram editor complement technical documents.

## Import, export, and back up

ZIP import and export tools make documents and files portable. Backup and restore tools help preserve a whole instance. Back up both the MySQL database and object storage for complete coverage.

## Security and identity

Alexandrie provides local authentication, password reset through SMTP, two-factor authentication, and session management. Organisations can configure up to ten OpenID Connect providers, including a provider connected to an LDAP directory.
