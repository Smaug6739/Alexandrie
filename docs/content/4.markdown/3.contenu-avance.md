## Mermaid diagrams

Insert a Mermaid diagram in its dedicated container. The source remains editable in the document and is rendered when reading it.

```md
:::mermaid
flowchart LR
  A[Document] --> B{Share?}
  B -->|Team| C[Permissions]
  B -->|Public| D[Sharing link]
:::
```

## Mathematical formulas

KaTeX supports short expressions with `$…$` and displayed equations with `$$…$$`.

```md
The relationship is $E = mc^2$.

$$
\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
```

## Colours, tags, and tooltips

```md
{color:blue}(Blue text)
[Red text]{color=#ef4444}
<tag teal>In review</tag>

[Hover here]{tooltip=Information shown on hover}
[[A short note shown on hover]]
```

Named colours use the application's theme variables. The bracket form accepts a hexadecimal colour (`#rgb` or `#rrggbb`).

## Footnotes and media

```md
This decision is documented.[^decision]

[^decision]: Meeting notes from 12 June.
```

Links to image, audio, and video files are rendered with a player or preview when the browser supports them.

## Links to Alexandrie documents

A document identifier written as `#123456789012345` becomes an internal link to that document. Within the application, its title is resolved automatically when available.
