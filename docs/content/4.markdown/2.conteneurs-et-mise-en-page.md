Containers add visual structure without leaving Markdown. Open a block with `:::` and close it with the same marker.

## Contextual messages

```md
:::green Tip
Keep documents close to their working context.
:::

:::yellow Warning
Check your backups before an update.
:::

:::red Important
Never publish passwords in a document.
:::
```

Available colours are `green`, `grey`, `blue`, `yellow`, `red`, and `teal`. Default headings match the block type; add text after the name to replace it.

## Details, centring, and columns

```md
:::details Further information
This content is collapsed by default.
:::

:::center
This paragraph is centred.
:::

::::columns
:::column
Left column
:::
:::column
Right column
:::
::::
```

The `no-print` container hides its content from PDF exports, which is useful for screen-only guidance.

## Frames, cards, and panels

`frame`, `card`, and `panel` blocks accept modifiers. Combine `border=<colour>`, `rounded`, `shadow`, `bordered`, `background=base|raised|overlay`, `gap=sm|md|lg`, and `title="…"`.

```md
:::card shadow bordered title="Decision"
The deployment uses a TLS reverse proxy.
:::

:::panel border=teal gap=md title="Remember"
A panel for supplementary information.
:::
```
