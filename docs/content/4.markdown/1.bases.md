Alexandrie renders Markdown directly in your documents. Standard syntax is supported along with extensions useful for technical documentation.

## Text and headings

```md
# Main heading
## A section

Text in **bold**, *italic*, __underlined__, ~~strikethrough~~,
and ==highlighted==.
```

`__text__` is rendered as underlined in Alexandrie. The `^superscript^` and `~subscript~` forms are supported too.

## Links, images, and quotes

```md
[Alexandrie on GitHub](https://github.com/Smaug6739/Alexandrie)
![An image](https://example.com/image.png)
![A resized image | 640x360](image.png)

> A useful quote.
```

You may specify only a width or both width and height after the image alt text.

## Lists, tasks, and tables

```md
- An idea
- Another idea
  - A nested item

1. First step
2. Second step

- [ ] To do
- [x] Done

| Item | Status |
| --- | --- |
| Migration | In progress |
```

Task checkboxes are interactive in the rendered document. Use lists for simple actions and a Kanban board when you need more visual tracking.

## Code and separators

Use backticks for inline code, three backticks for a code block, and `---` to separate sections. Code blocks receive syntax highlighting according to their specified language.
