This page covers features that go beyond standard Markdown. Each example can be copied into a document and adapted to your content.

## Mermaid diagrams

Use a `mermaid` block for diagrams. Alexandrie keeps the source editable and renders the diagram when the document is displayed.

```md
:::mermaid
flowchart TD
A[Write] --> B{Review?}
B -->|Yes| C[Publish]
B -->|No| D[Revise]
:::
```

The Mermaid source is captured as-is. Keep the diagram source inside the block and do not indent the closing marker by four spaces.

## Mathematical formulas

Use single dollar signs for inline formulas and double dollar signs for displayed formulas.

```md
The famous equation is $E = mc^2$.

$$
\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
```

Formulas are rendered with KaTeX. KaTeX is configured not to stop the document when an expression contains an error, so review complex formulas in the rendered preview.

## Colours

The function syntax colours inline content and still allows inline formatting inside the parentheses:

```md
{color:blue}(Blue text)
{color:#ef4444}(Red text)
{color:green}(This is **important**)
```

Named values are converted to application CSS variables, such as `var(--blue)` or `var(--primary)`. This means that names such as `blue`, `red`, `green`, `yellow`, `primary`, `purple`, `pink`, and `teal` follow the active theme.

The bracket syntax accepts hexadecimal colours:

```md
[Red text]{color=#ef4444}
[Short hex]{color=#f00}
```

Do not put a space between the closing `]` and `{color=...}`.

## Tooltips

Use the bracket form when the visible text should explain what the reader can hover or focus:

```md
[Hover over this text]{tooltip=More context appears here}
```

Use the marker form when the explanation should remain compact:

```md
This sentence has an additional hint.[[The hint is shown when the marker is hovered or focused.]]
```

The visible text in the first form supports inline Markdown. Tooltip content itself is plain text.

## Footnotes

Add a reference with `[^id]` and define the note with `[^id]:` at the beginning of a line.

```md
This decision was discussed during the release meeting.[^release]

Another statement can use a numeric note.[^1]

[^release]: Notes from the release meeting.

[^1]: A short supporting reference.
```

Alexandrie appends the footnote list to the end of the rendered document and adds a back link to each note. Identifiers can contain letters, numbers, and other characters except `]`.

## Audio, video, and SVG

Images whose source ends in a supported media extension become native HTML5 players:

```md
![Product demonstration](demo.mp4)
![Audio note](meeting.mp3)
```

Supported video extensions include `.mp4`, `.webm`, `.ogg`, `.mov`, `.avi`, `.mkv`, `.flv`, and `.wmv`. Supported audio extensions include `.mp3`, `.wav`, `.ogg`, `.m4a`, `.flac`, and `.aac`.

SVG sources are embedded as objects:

```md
![Architecture diagram](architecture.svg)
```

Normal image sizing also applies to media syntax:

```md
![Demo | 640x360](demo.mp4)
```

## Links to Alexandrie documents

An identifier made of 15 to 20 digits after `#` becomes an internal document link:

```md
Read the related document: #726782907684193440
```

When Alexandrie can resolve the identifier, the document name is displayed. Otherwise, the numeric identifier is kept as the label.

## HTML and custom tags

HTML is enabled, so simple custom elements can be used when a theme provides matching styles:

```md
<tag blue>Blue tag</tag>
<tag green>Green tag</tag>
<tag red>Red tag</tag>
<tag orange>Orange tag</tag>
<tag grey>Grey tag</tag>
<tag teal>Teal tag</tag>
```

Inline HTML can also provide a one-off style:

```md
<span style="color: red">Red text</span>
```

Use trusted HTML only. HTML is not a replacement for the built-in containers: prefer the documented syntax when a feature already exists.

## Common combinations

Advanced features can be combined with containers and ordinary Markdown:

```md
:::info-blue Release formula
The calculation uses $E = mc^2$ and links to [the reference](https://example.com).
:::
```

When a block does not render as expected, check the opening name, the number of colons, and whether the syntax requires a value or title on the same line.
